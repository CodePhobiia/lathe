    Launch freeze¶

    A launch freeze is in effect for v0.2.0rc1 as of 2026-04-28. No public release artifacts may be published from this branch until:

    1. Every Phase 0–18 task in readiness-tasks.md is checked or has a formally recorded exception in this packet.
    2. The Phase 18 go/no-go meeting has been held and the verdict recorded in this file.
    3. Legal/privacy sign-off in docs/legal/compliance-review-v0.2.0rc1.md is complete OR an explicit launch blocker is recorded if review is unavailable.

    Audit-output exclusion policy¶

    tmp_audit_*, tmp_*, dist_*, warm_*, v05_*, and cache_probe_* directories at the repo root are explicitly NOT release evidence. They are transient build/audit scratch dirs (CLAUDE.md repo conventions) and must not be referenced from this packet. All evidence cited here lives under docs/, tests/, configured CI, or under a stable dist/ build that is rebuilt from a clean checkout for the release-evidence run.

    Stable-release-claim restriction¶

    Until this checklist is green:

    • Public copy may use "v0.2.0 release candidate", "pre-release", or "early-access reference scaffold".
    • Public copy may NOT use "production-ready", "stable", "1.0", "GA", or imply that downstream consumers should depend on the release for shipping work without their own evaluation.

    This restriction is recorded in docs/release/launch-narrative-v0.2.0rc1.md and docs/release/decision-log-v0.2.0rc1.md once those exist.

    • pip-audit -r requirements*.txt --strict cannot run inside this worktree because both requirements files start with -e . and pip-audit's hashes-required mode rejects an editable install with no single hashable file. The transcripts capture the failed primary command, then a documented fallback to pip-audit --skip-editable against the active venv. The fallback reports two known vulnerabilities: pip 26.0.1 CVE-2026-3219 (the Phase 6 gate) and lxml 5.4.0 CVE-2026-41066 (new finding — see Phase 9 follow-up). Both transcripts skip the in-tree lathe and editable vggt packages.

The wheel installs cleanly, python -m lathe.cli doctor and the lathe console script both succeed, and .lathe_lark_cache does NOT appear in the install venv's site-packages. The 3.11-specific and 3.12-specific legs are requires-human.
