    Known Bugs — v0.2.0rc1¶

    Status¶

    This is the known-bugs register for v0.2.0rc1, derived from the audit captured in plans/10_bugs_errors.md (16 findings after the 2026-04-23 amendment: 15 originals − 2 removed (C3, Mi5) + 3 added (M4b, M8, M9)). Every row tracks a single finding. A row leaves the register only when (a) the fix has landed AND (b) the regression test named in plans/10_bugs_errors.md exists, is wired into CI under the bug_regression marker, and is green on the release branch.

    As of 2026-04-28, no regression tests under the bug_regression marker exist in the repository (grep -rn '@pytest.mark.bug_regression' tests/ returns no files; tests/bugs/ contains only __init__.py and test_parser_budgets.py). All 16 findings are therefore tracked as open below.

    Default owner: Tal Merri / @talmerri. The default target-fix track is the Plan 10 phasing in plans/10_bugs_errors.md. Anything that does not land by the release-gate cutover for v0.2.0rc1 final must either be re-targeted with an explicit owner+date or accepted as a release exception in docs/release/decision-log-v0.2.0rc1.md.

    Severity legend (matches docs/support/readiness-checklist.md):

    • P0 — security, privacy/telemetry leak, broken install, certification path entirely broken. Plan 10 "Critical" maps to P0.
    • P1 — correctness regression, hero-family failure, blocking docs. Plan 10 "Major" maps to P1.
    • P2 — non-blocking bug or hygiene gap. Plan 10 "Minor" maps to P2.
    • P3 — tracked enhancement.
