    Lathe v0.5 — five-asset study¶

    Plan 09 Phase 4. Last measured: 2026-04-24.

    This is the headline benchmark document for Lathe v0.5. It compares Lathe against five established 3D asset pipelines on the same five reference assets.

    Read me first: the methodology, metric definitions, and rules for adding a competitor live in methodology.md. Per-run raw JSON lives under data/. This document is the human-readable summary; the JSON is the ground truth.

    What was measured¶

    • 5 reference assets: industrial_crate, sci_fi_wall_panel, mechanical_door, control_pedestal, service_cabinet.
    • 8 system columns: Lathe-fallback, Lathe-learned, Meshy, Hunyuan3D, Luma, Houdini HDA + SideFX Labs, Quixel Megascans, Blender-by-hand.
    • Harness: scripts/run_benchmark.py.
    • Host: Windows 10 Home, repo .venv (Python 3.12), no GPU, psutil not installed in this run (so peak_memory_mb is null).

    To reproduce:

    python scripts/run_benchmark.py --lathe-only

    The harness auto-selects .venv/Scripts/python.exe (or .venv/bin/python on POSIX) so that Lathe's downstream deps (trimesh, Pillow, etc.) are on the path regardless of how the harness itself is launched.

    Lathe-learned results¶

    Pending. Run with:

    python scripts/run_benchmark.py --runtime-config examples/runtime_configs/auto_learned.json

    Requires provider wiring (Hunyuan HTTP or local VGGT) — see the examples/runtime_configs/ directory. When populated, each row should record both the attempted provider and the actually-used provider, since Lathe's mux logs both under shape_backend_report.provider_attempted vs. provider_selected.

    Godot-import grade (pending)¶

    The .glb files from Lathe-fallback above need to be import-tested in Godot once the addon MVP (Plan 09 Phase 2, task #1) lands. Goal: all 5 load without material or scale remapping and apply the emitted collision proxy correctly.

    Iteration speed (pending)¶

    The methodology calls for a "make it 10% wider" re-export test per system. Lathe: edit .lth, re-run lathe build, measure wall clock. Competitors: re-prompt / re-author per their per-competitor doc. Not captured in this wave.
