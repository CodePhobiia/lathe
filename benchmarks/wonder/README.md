# Wonder Benchmark Prompt Corpus

This directory contains the Phase 31 Wonder benchmark prompt corpus. The JSON
file is intentionally compact and deterministic: it names the ten benchmark
scenes, three style variations per scene, three patch operations per scene, and
the scoring focus for each prompt.

The corpus is input data only. It does not claim that any scene has been built,
rendered, exported, or accepted until a benchmark report records measured
timings and scores.

Primary file:

- `prompts.json`: `lathe.wonder_benchmark_prompts.v1`
