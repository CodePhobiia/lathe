    Plan Completeness — Honest Backlog¶

    As of 2026-04-24, 74 commits on main + tag v0.1.0. This document is the honest state of what's shipped vs what's open across the 10 original plans from the repository review.

    V0.2 update (2026-04-25): 21 additional commits on main have landed every V0.2 epic from docs/next_version_roadmap.md save OPS-1 (push to public GitHub — requires a credentialed human action). Version bumped to 0.2.0rc1 in pyproject.toml. 922 tests pass on the core suite. See CHANGELOG.md § [0.2.0-rc.1] for the per-epic breakdown.

    "Touched" ≠ "done." Use this doc when planning future waves; don't trust the session-scale WAVE{N}_BACKLOG.md files alone.

    Correction (2026-04-25): Package/runtime metadata is aligned at 0.2.0rc1; the public language contract remains v0.1. Local collection currently reports roughly 1.2k tests depending on installed extras and Python version, not 922. The suite is intentionally partitioned into fast, golden, property, fuzz, and example-corpus lanes because a single unpartitioned full run is too slow for the PR matrix.

    Plan 01 — Code Quality (~95%)¶

    Done. 8 god-modules decomposed to ≤500 LOC (parser/, shape/, providers/, core/ including per-stage split of executor.py, checker/, blueprints/*, cli/, blender/, + capabilities.py slimmed to 506, resolver.py 540 ADR-accepted). Exception hierarchy at lathe/errors.py (15 classes). 27 except Exception narrowed to zero. 17 production assert converted to explicit raises. Ruff BLE001 + S101 green. [tool.ruff] + [tool.mypy] config landed in pyproject.toml.

    Open. - CQ-1. Enable mypy --strict in CI on the strict-tier modules (parser.*, normalizer, resolver, checker, planner, shape_ir, asset_graph, conformance, backends, cli, errors). Config exists; gate not wired. - CQ-2. pre-commit install in bootstrap scripts. Config exists at .pre-commit-config.yaml; hook not auto-installed.

    Plan 02 — Documentation (~95%)¶

    Done. LICENSE (Apache-2.0). CHANGELOG.md / CONTRIBUTING.md / CODE_OF_CONDUCT.md (Covenant 2.1 by reference) / SECURITY.md. mkdocs.yml with nav for 4 tutorials + 13 cookbook recipes + 4 architecture diagrams + 36 API stubs + ADR index. mkdocs build --strict green. 30 stdlib .lth files with // doc: blocks. 473 Google-style docstrings across 103 lathe/ modules. Ruff D100-D400 green on priority list.

    Open. - DOC-1. 102 ruff-D residuals on non-priority modules (scaffolds, adapters, transport, several runtimes). - DOC-2. D104 (public package) + D107 (public __init__) — 18 sites total, untouched. - DOC-3. API reference docs don't render because target modules have low docstring density — strengthen mkdocstrings output.

    Plan 03 — Architecture (~85%)¶

    Done. 6 ADRs backfilled (docs/adr/0001..0006.md) + template + README index + pre-existing 0007-resolver-loc-exception.md. Entry-point plugin registry with 4 groups (lathe.backends, lathe.stacks, lathe.providers.shape, lathe.validators). import-linter config at .importlinter with 4 contracts. Validator composition contract at lathe/validators/composition.py with ValidatorPipeline routing through the 5 existing validators. Second backend stack lathe.stack.soft_surface_prop_v1 registered + satchel hero certifies.

    Open. - ARCH-1. BL-40 — full Phase 6b deep-stack proof: real Catmull-Clark subdivision topology, non-planar soft-padding xatlas, per-vertex principal-curvature + per-edge C¹/C² continuity validators. Current BL-34 is MVP-only. - ARCH-2. .importlinter seeded permissive with ignore_imports list. Progressive tightening strategy documented but not applied. Target: zero ignore_imports by V0.5. - ARCH-3. lathe/contracts/ package mentioned in ADR-0005 but never created; Protocol definitions for StageBackend/ShapeProvider/BackendStack/Validator live scattered across modules. Consolidate.

    Plan 04 — Test Coverage (~80%)¶

    Done. Tests grew 70 → 847+ across ~60 new files. Tranches A/B/C complete. 126 property-based tests. 27 golden snapshots. Contract pin test. Ruff BLE001/S101 green. Coverage gate at 65% (ratchet against regression). Contract hash bit-stable: 51e02c6e…671b085.

    Open. - BL-39. Coverage 69.66% → 85%. Target files below 70%: validation.py (51%), executor.py orchestration branches, provider fallback paths (not exercised by native-only tests), CLI error-paths per subcommand, parser/checker/resolver error-path coverage. Est 2–3 days. - TEST-1. Mutation testing (mutmut) in pyproject.toml dev extras but never run. Target: mutation score ≥70% on geometry_kernel, exact_solids, checker, resolver, conformance.

    Plan 07 — Security (~50%) — biggest gap¶

    Done. schema/runtime_config.schema.json + lathe/runtime_config.py::load_runtime_config validates via jsonschema.Draft202012Validator. lathe/net.py::safe_urlopen with SSRF guards (scheme allowlist, private-IP rejection, TLS min 1.2, content-type pre-check, size cap). lathe/subproc.py::run_sandboxed with env-allowlist + stderr scan + timeout. Both Blender subprocess sites (blender_execution.py + core/stages/topology.py) migrated. capabilities.py:395 SSRF site closed. JSON ingress audit at docs/security/json_ingress_audit.md.

    Open — P0 BEFORE going public. - SEC-1. Path hardening — lathe/paths.py::safe_resolve(root, user) not landed. Plan 07 Phase 2 full surface: RFC1918 path-traversal rejection, Windows reserved names, 8.3 short names, trailing dot, ADS file:stream, \\?\ extended-length, reparse points, case-insensitive collisions. Current state: path inputs accepted as-is. - SEC-2. Binary parser hardening — lathe/mesh_ingest.py::safe_load_mesh not landed. Plan 07 Phase 6: size caps, format allowlist, magic-byte sniff, PIL size cap, NaN/Inf rejection. Current state: trimesh.load called with raw user bytes. - SEC-3. Secret scanning — .gitleaks.toml + pre-commit hook not landed. Plan 07 Phase 8. - SEC-4. SBOM generation — syft / cyclonedx + cosign keyless signing on release. Plan 07 Phase 9. release.yml publishes PyPI but not SBOM. - SEC-5. Static-analysis CI — Bandit + Semgrep + CodeQL + Trivy workflows not landed. Plan 07 Phase 10. - SEC-6. Threat model — docs/security/threat_model.md not landed. Plan 07 Phase 11 STRIDE table. - SEC-7. Blender sandbox — docs/security/blender_sandbox.md is a design doc only; no sandboxing container profile (docker/blender.Dockerfile with --network=none) landed. - SEC-8. .lth prompt-injection handling when user content flows into learned-provider prompts. Flagged in Plan 07 amendment; no mitigation implemented.
