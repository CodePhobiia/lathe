What Lathe is

Lathe is a declarative language for 3D asset intent. A .lth file describes what an asset is, how to build it, and what counts as passing. The compiler emits certified production-ready packages (USD / GLB / GLTF / OBJ).

What this page will become

  • A Monaco editor for .lth sources, with grammar-aware highlighting.
  • A WebAssembly-hosted lathe compiler running under Pyodide — no install, no server.
  • Live <model-viewer> preview of the compiled GLB output.
  • Hero examples preloaded from examples/*.lth.

Run Lathe locally today

git clone https://github.com/example/lathe
cd lathe
scripts/bootstrap_local.sh --dev
python -m lathe.cli check examples/courier_drone.lth
python -m lathe.cli build examples/courier_drone.lth courier_drone --out dist
